# NGG AI Assessment Platform — חבילת עיצוב

החבילה כוללת את כיוון העיצוב שנבחר (המודולרי) בלבד.

## מה יש בפנים
- `index.html` — דף פתיחה עם קישורים לכל המסכים. פותחים אותו בדפדפן בלחיצה כפולה.
- `screens/` — 11 מסכים: 4 של צד NGG, 2 של דשבורד הלקוח ו-5 של שאלון המשיב במובייל.
  מסכי השאלון מקושרים זה לזה, ובמסכי הסולם והבחירה המרובה הבחירה עובדת.
- `tokens.css` — ערכי העיצוב: צבעים, פינות, ריווח וגופנים.
- `DESIGN_SYSTEM.md` — מסמך מערכת העיצוב, באנגלית, עבור Claude Code.
- `CLAUDE.md` — הוראות ש-Claude Code קורא אוטומטית כשהוא נפתח בתיקייה.
- `reference/` — הטוקנים המקוריים של מערכת העיצוב של NGG.

## איך משתמשים עם Claude Code
1. פורסים את קובץ ה-Zip לתוך תיקיית הפרויקט במחשב.
2. מומלץ להוסיף לאותה תיקייה, בתוך תת-תיקייה בשם `docs`, את מסמך האפיון `NGG_AI_Assessment_Interface_Spec.md`.
3. פותחים טרמינל בתיקיית הפרויקט ומפעילים את Claude Code.
4. Claude Code יקרא את `CLAUDE.md` ויבין שאלה מסכי ייחוס ולא קוד סופי.

## חשוב
כל המספרים ושמות הלקוחות בחבילה הם נתוני הדגמה. רשימת התכנים שעדיין צריך להשלים נמצאת בסעיף 9 של `DESIGN_SYSTEM.md`.
